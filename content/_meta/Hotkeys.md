> I was foolish enough to purchase a RAZER Basilisk v3 x Hyperspeed mouse for my current running [[System|system]]. Unfortunately, the operating systems are not compatible and the [RAZER Synapse](https://www.razer.com/pc/software) does not recognize the mouse despite 2.4 or BT connection. I found that [BetterTouchTool](https://folivora.ai/) was a decent substitute. I use the following macros and hotkeys to maneuver around this site.

### BetterTouchTools

#### Universal

| Command          | Effect                                   |
| ---------------- | ---------------------------------------- |
| Button 3         | Move Right a Space                       |
| Button 4         | Move Left a Space                        |
| Scroll Button    | Show/Hide Clipboard / Pasteboard History |
| SHIFT + Button 3 | Show Window Switcher for All Open Apps   |

### Obsidian

| Command          | Action        | Impact          |
| ---------------- | ------------- | --------------- |
| CMD+Button 3     | CMD+right     | Next File       |
| CMD+Button 4     | CMD+left      | Previous File   |
| OPT+CMD+Button 3 | OPT+CMD+right | Next Folder     |
| OPT+CMD+Button 4 | OPT+CMD+left  | Previous Folder |
